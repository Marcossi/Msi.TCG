## Propósito de los ADRs

Un ADR captura una decisión arquitectónica con su contexto, alternativas consideradas y consecuencias. Permite entender el "por qué" de las decisiones sin depender del historial de conversaciones.

## Convenciones

- **Estado**: `Accepted` | `Deprecated` | `Superseded by ADR-NNN`
- **Numeración**: Secuencial (ADR-001, ADR-002, ...)
- **Ubicación**: Un fichero por ADR, nombrado `ADR-NNN-titulo-corto.md`
- **Consulta**: Este README es el punto de entrada. Los implementadores deben revisar el índice antes de cambios estructurales.
